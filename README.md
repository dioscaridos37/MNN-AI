# MNN-AI

Android-приложение для локального чата на базе MNN-Pocket-0.3B.

## Сборка
GitHub Actions автоматически собирает debug APK и ZIP исходников из корня репозитория при push в main.
Ручной запуск: Actions → Android build → Run workflow.

## Текущий статус
Добавлена Android-оболочка чата и автоматическая сборка. MNN runtime и веса модели пока не подключены.
