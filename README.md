# DIX AI

Офлайн ИИ-ассистент для Android на базе Vikhr-Qwen-2.5-1.5B-Instruct Q4_K_M (GGUF).

## Возможности
- Локальная генерация через llama.cpp, без платного API.
- Первая загрузка GGUF-модели (~986 МБ) из Hugging Face с отображением прогресса и продолжением прерванной загрузки.
- Русский интерфейс, локальная история диалогов.
- Голосовой ввод Android и озвучка ответов системным TTS.
- Liquid Glass интерфейс, анимированный фон, пружинные переходы и слайдеры настроек.

## Установка
1. Скачайте APK из GitHub Releases.
2. Установите приложение.
3. При первом запуске подключитесь к Wi-Fi и дождитесь загрузки модели.
4. После загрузки чат работает офлайн.

Модель хранится в приватной памяти приложения и не входит в APK. Для файла модели требуется около 1 ГБ свободного места; для скачивания рекомендуется иметь не менее 1,2 ГБ свободного пространства.

## Сборка
GitHub Actions автоматически собирает APK при push в main и публикует его в Releases. Исходники llama.cpp фиксируются на проверенном коммите и загружаются в процессе сборки.
